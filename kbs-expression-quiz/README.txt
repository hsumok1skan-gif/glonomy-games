GitHub에 올리는 방법
1. glonomy-games 저장소의 루트에서 Add file → Upload files를 누릅니다.
2. 이 kbs-expression-quiz 폴더 전체를 업로드합니다.
3. Commit changes를 누릅니다.
4. 메인 index.html에서 퀴즈 링크를 kbs-expression-quiz/ 로 연결합니다.
